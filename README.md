# Small Android Apps

## PiFauna

PiFauna is an experimental **phone-speaker sound generator** for Android. It offers configurable audible/high-frequency tones, a timed session and device-safety controls. **It is not a validated pest repellent**: do not rely on it to protect people, animals or property.

- [Android application](pifauna/README.md)
- [Architecture and safety specification](docs/ARCHITECTURE.md)
- [Test and release checklist](docs/TESTING.md)
- [Figma design](https://www.figma.com/design/oPIHDBtBn2H7xcbPmjq2PX)

Implementation is on `feat/pifauna-phone-audio`. Android Studio/Gradle build verification is still required.
